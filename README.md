# نظام تسجيل حضور الطلاب 📚

نظام إلكتروني متكامل لتسجيل حضور الطلاب بواسطة أرقام التعريف (3 أو 4 أرقام)

## ✨ المميزات

### 🆕 1️⃣ إدارة السجلات (جديد!)
- **إنشاء سجل لكل يوم** - سجلات منفصلة لكل يوم أو حدث
- **سجل سريع لليوم** - إنشاء سجل تلقائياً بتاريخ اليوم
- **سجل مخصص** - إنشاء سجل بأي اسم تريده
- **تفعيل السجل** - اختر السجل الذي تريد تسجيل الحضور فيه
- **حذف السجلات** - إمكانية حذف السجلات القديمة
- **البيانات محفوظة للأبد** ✓

### 2️⃣ تسجيل الحضور
- واجهة سهلة الاستخدام مع لوحة أرقام رقمية
- دعم رموز الطلاب من 3 أو 4 أرقام
- تسجيل تلقائي مع التاريخ والوقت
- رسائل تأكيد فورية بعد التسجيل

### 3️⃣ إدارة الطلاب
- إضافة طلاب جدد بسهولة
- تعيين رمز فريد لكل طالب (3-4 أرقام)
- عرض قائمة بجميع الطلاب المسجلين
- حذف الطلاب عند الحاجة
- **البيانات محفوظة تلقائياً وبشكل دائم** ✓

### 4️⃣ سجل الحضور
- عرض جميع سجلات الحضور بشكل منظم
- **فلترة حسب السجل** - عرض حضور سجل معين أو الكل 🆕
- معلومات تفصيلية (الرمز، الاسم، التاريخ، الوقت)
- **تصدير إلى Excel** - ملف .xlsx كامل مع تنسيق جميل
- **تصدير إلى CSV** - ملف نصي يدعم العربية بشكل كامل
- **مشاركة السجل** - نسخ أو مشاركة السجل كنص عبر WhatsApp وغيره
- إمكانية مسح جميع السجلات
- **الحفظ التلقائي للأبد** ✓

### 5️⃣ الإعدادات والنسخ الاحتياطي
- **عرض معلومات التخزين** - اعرف كم من المساحة مستخدمة
- **ملخص البيانات** - عدد الطلاب وسجلات الحضور
- **تحميل نسخة احتياطية** - احفظ جميع البيانات في ملف JSON
- **استعادة من نسخة احتياطية** - استرجع البيانات من ملف محفوظ
- **معلومات مهمة** عن كيفية حفظ واسترجاع البيانات

## 🚀 كيفية الاستخدام

### الخطوة 0: إنشاء سجل حضور (البداية) 🆕
1. عند فتح الموقع لأول مرة، ستبدأ في تبويب "📋 السجلات"
2. انقر على **"سجل جديد (اليوم)"** لإنشاء سجل بتاريخ اليوم تلقائياً
3. أو انقر على **"سجل مخصص"** لإنشاء سجل باسم معين (مثل: حضور الاختبار)
4. السجل الجديد سيكون نشطاً تلقائياً
5. يمكنك التبديل بين السجلات في أي وقت

💡 **ملاحظة**: يجب إنشاء وتفعيل سجل قبل تسجيل الحضور

### الخطوة 1: إضافة الطلاب
1. انقر على تبويب "إدارة الطلاب"
2. أدخل اسم الطالب
3. أدخل رمز مكون من 3 أو 4 أرقام (فريد لكل طالب)
4. انقر على "إضافة طالب"

### الخطوة 2: تسجيل الحضور
1. تأكد من وجود سجل نشط (يظهر في الأعلى)
2. انقر على تبويب "📝 تسجيل الحضور"
3. اطلب من الطالب إدخال رمزه باستخدام لوحة الأرقام
4. سيتم تسجيل الحضور تلقائياً في السجل النشط عند إدخال 3 أو 4 أرقام
5. ستظهر رسالة تأكيد بنجاح التسجيل

### الخطوة 3: مراجعة وتصدير السجلات
1. انقر على تبويب "سجل الحضور"
2. راجع جميع سجلات الحضور بالتفصيل
3. اختر طريقة التصدير المناسبة:
   - **Excel**: للحصول على ملف .xlsx احترافي
   - **CSV**: لملف نصي بسيط يمكن فتحه في أي برنامج
   - **مشاركة**: لنسخ السجل كنص ومشاركته عبر WhatsApp أو Email
4. سيتم تنزيل الملف أو نسخه حسب الخيار المختار

### الخطوة 4: النسخ الاحتياطي (مهم جداً!)
1. انقر على تبويب "⚙️ الإعدادات"
2. راجع معلومات التخزين وملخص البيانات
3. **انقر على "تحميل نسخة احتياطية"** لحفظ جميع البيانات
4. احفظ الملف في مكان آمن (جهازك أو Google Drive)
5. لاستعادة البيانات: انقر "استعادة نسخة احتياطية" واختر الملف

## 💾 حفظ البيانات - دائم وآمن

### ✅ الحفظ التلقائي
- **يتم حفظ جميع البيانات تلقائياً** عند كل إضافة أو تعديل
- **البيانات محفوظة للأبد** في المتصفح (LocalStorage)
- **تبقى البيانات محفوظة** حتى بعد إغلاق المتصفح أو الجهاز
- **لا يتم إرسال أي بيانات** إلى الإنترنت (خصوصية كاملة 🔒)

### 📦 النسخ الاحتياطي
- **تحميل نسخة احتياطية**: احفظ ملف JSON يحتوي على جميع البيانات
- **استعادة من نسخة احتياطية**: استرجع البيانات من ملف محفوظ سابقاً
- **ينصح بعمل نسخة احتياطية** كل فترة للحفاظ على البيانات

### ⚠️ تحذير مهم
- قد تُحذف البيانات عند **مسح بيانات المتصفح** أو الكوكيز
- احتفظ بنسخة احتياطية في مكان آمن (على جهازك أو في السحابة)

## 🛠️ التقنيات المستخدمة

- **React** - إطار عمل واجهة المستخدم
- **TypeScript** - للكتابة القوية
- **Tailwind CSS** - للتصميم الجميل
- **XLSX** - لتصدير البيانات إلى Excel
- **Vite** - أداة البناء السريعة

## 📋 ملاحظات مهمة

- تأكد من عدم تكرار أرقام الطلاب
- يمكن استخدام أرقام من 3 أو 4 خانات فقط
- يتم ترتيب السجلات من الأحدث إلى الأقدم
- عند تصدير الملفات، يتم تسمية الملف بتاريخ التصدير
- **تنسيقات التصدير المتاحة:**
  - **Excel (.xlsx)**: الأفضل للعمل الاحترافي وفتحه في Microsoft Excel
  - **CSV**: يعمل مع جميع البرامج ويدعم اللغة العربية
  - **مشاركة كنص**: مثالي للمشاركة السريعة عبر WhatsApp أو Email

## 🎨 واجهة المستخدم

النظام يدعم اللغة العربية بالكامل مع:
- كتابة من اليمين إلى اليسار (RTL)
- تصميم عصري وجذاب
- ألوان واضحة ومريحة للعين
- استجابة كاملة للأجهزة المختلفة (موبايل، تابلت، كمبيوتر)
